# C# 程序设计课程作业集

WinForm 综合练习、数据结构可视化与汉诺塔游戏

## 目录结构

```
006/          主工程：综合练习集（.sln / .csproj 可直接用 Visual Studio 打开）
hannuota/     汉诺塔游戏（含最高分记录功能）
HTML/         HTML 基础练习（留言板等）
```

## 内容说明

**006 —— 综合练习集**

| 模块 | 内容 |
|---|---|
| `C2_*` | 棋类小游戏、OLE 对象嵌入、工程计算器 |
| `C3_*` | 类与对象练习、小游戏 |
| `C6_*` | SQL Server 数据库的增删查改（ADO.NET） |
| `C9_*` | 线性表、栈、树的数据结构实现与界面演示 |
| `C10_*` | 二叉树遍历、冒泡 / 插入 / 选择排序的算法可视化 |

**hannuota —— 汉诺塔**

递归算法实现 + 图形化演示 + 最高分排行榜（`ScoreEntry` / `HighScoresForm`）。

## 技术栈

C# · .NET Framework WinForms · ADO.NET · SQL Server

## 复现提示

用 Visual Studio 打开 `006.sln` 或 `hannuota.sln`，还原 NuGet 包后编译。数据库相关示例需先建库并修改连接字符串。

> **安全说明**：源码与配置中涉及的数据库连接口令，已全部替换为占位符 `YOUR_PASSWORD_HERE`。本地复现时请自行配置数据库账号。
